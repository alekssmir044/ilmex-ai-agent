# Агент-аналитик данных (data-analyst)

Диалоговый агент на [Mistral Agents SDK](https://docs.mistral.ai/studio/agents/getting-started/quickstart):
принимает ссылку на CSV-файл в Google Drive, загружает данные и отвечает на вопросы
с реальными числами. Файл он берёт через ваш подключённый Google Drive, анализ
выполняет фиксированными инструментами — никакого произвольного кода.

## Инструменты

| Идентификатор | Что делает |
| --- | --- |
| `data.load_csv` | Загружает содержимое CSV (прочитанное коннектором `google_drive_mcp`) в набор данных сессии; возвращает размерность и сводку |
| `data.describe_columns` | Описывает столбцы: типы, пропуски, уникальные значения, min/max/mean |
| `data.filter_rows` | Отфильтровывает строки по условию (=, !=, >, in, contains, isnull, …) и возвращает до 100 строк |
| `data.group_by` | Группировка по 1–3 столбцам с агрегатами (count, nunique, sum, mean, median, min, max, std), сортировкой |

Коннектор: `google_drive_mcp` (поиск и чтение файлов в вашем Google Drive, OAuth от вашего аккаунта).
Песочницы и произвольного кода нет. Набор данных хранится в сессии (плюс файловый кэш воркера),
поэтому в рамках одного диалога агент помнит файл и весь разговор.

## Запуск на своём компьютере

```bash
uv sync
uv run python main.py          # самопроверка инструментов без модели
uv run --env-file .env agents chat   # чат в терминале (нужен ключ в .env)
```

Агент берёт ключ из `MISTRAL_API_KEY` (см. `.env.example`).

## Деплой на Mistral Cloud

```bash
git push                      # деплой собирает запушенный коммит
uv run --env-file .env agents deploy
```

`agents deploy` развернёт агента как управляемое рабочее развёртывание (hardened, потому что
агент действует от вашего имени через коннектор). Дальше чат с агентом доступен по ссылке
из вывода деплоя (Vibe Code Web) и по имени:

```bash
uv run --env-file .env agents chat data-analyst
```

Программный доступ: `agents.Agent.load_from(agent_name="data-analyst")` и сессии
(`start_session` → `session.run(...)`), идентификатор сессии сохраняйте для продолжения диалога.

## Требования

- Ключ `MISTRAL_API_KEY`, чей пользователь имеет роль с доступом к Workflows (Developer / Workspace Contributor) — [роли](https://admin.mistral.ai).
- Коннектор `google_drive_mcp`, подключённый вашим аккаунтом (Studio → Context → Connectors).
- Для деплоя: GitHub-репозиторий проекта и подключённый GitHub-коннектор (платформа клонирует репозиторий через него).

## Проверки

```bash
uv run python main.py
```

`OK: все проверки инструментов пройдены` — загрузка, профиль столбцов, фильтр, группировка
и восстановление набора после перезапуска воркера.
